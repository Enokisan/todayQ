# todayQ 📝

## 今日の問いジェネレーター

> **毎日ひとつの「問い」で、思考を深める習慣を**

AI時代だからこそ、自分で考える力が重要。todayQは、日々の思考を深めるための「問い」を提供するシンプルなWebアプリです。

## ✨ 特徴

- **毎日異なる問い**: 日付ベースで一貫した問いを表示
- **AI質問生成**: 過去のメモから思考傾向を分析し、個人に最適化された問いを生成
- **思考の記録**: 140文字で自分の答えをメモ
- **振り返り機能**: 過去の思考を振り返って成長を実感
- **シンプル設計**: 余計な機能はなし、思考に集中

## 🎯 なぜtodayQを作ったのか

現代は情報過多の時代。AIが即座に答えを提供してくれるからこそ、**自分で問いを立て、考える力**が重要になっています。

- 情報を鵜呑みにしない習慣
- 表面的でない、深い思考
- 内発的な動機による学び
- 批判的思考力の育成

todayQは、これらを日常的に育むためのツールです。

## 🚀 使い方

1. **朝**: アプリを開いて今日の問いを確認
2. **考える**: 日中、その問いについて意識的に考える
3. **記録**: 夜、140文字で自分なりの答えをメモ
4. **振り返り**: 週末に過去の記録を見返す

## 📱 技術スタック

- **Frontend**: Vue.js 3 (Composition API)
- **Storage**: localStorage (シンプル性重視)
- **Styling**: CSS3 (グラデーション、ガラスモーフィズム)

## 🔧 開発・実行方法

```bash
# プロジェクトをクローン
git clone https://github.com/your-username/todayQ.git
cd todayQ

# 依存関係をインストール
yarn

# 環境変数の設定（AI質問生成機能を使用する場合）
cp .env.example .env
# .envファイルにOpenAI APIキーを設定してください

# 開発サーバーを起動
yarn dev

# ビルド（本番環境用）
yarn build
```

### 🤖 AI質問生成機能の設定

AI質問生成機能を使用するには、OpenAI APIキーが必要です：

1. [OpenAI](https://openai.com/)でアカウントを作成し、APIキーを取得
2. プロジェクトルートに`.env`ファイルを作成
3. 以下の内容を追加：

```env
VITE_OPENAI_API_KEY=your_openai_api_key_here
```

**注意**: APIキーは絶対に公開しないでください。`.env`ファイルは`.gitignore`に含まれています。
